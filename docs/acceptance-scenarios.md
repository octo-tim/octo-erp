# 인수 시나리오 (Acceptance Scenarios)

RFP 10장 검수 기준의 핵심 E2E 4종과 경계시험을 Given/When/Then으로 정의한다. 각 시나리오는 자동 통합시험(`tests/integration`, `tests/e2e`)과 1:1로 대응하며, 시험 파일명은 시나리오 ID를 따른다.

## A. 핵심 E2E

### E2E-01 견적 → 주문 → 매출전표 → 결재 → 확정 → 출고 → 회계분개 → 수금 → 채권소진
- Given 품목 A(과세, 재고 100개 @10,000원 창고 W1), 거래처 C(여신한도 50,000,000원, 미수 0), 영업 사용자 U1(사업부 D1 범위), DEC-03 정책상 매출전표 5,000,000원 이상은 결재 필수(시험용 정책 버전)
- When U1이 견적(A×10 @100,000)을 등록·확정하고, 견적에서 주문으로 10개 중 6개를 전환하고, 주문에서 매출전표(6개, 창고 W1)를 생성한 뒤 결재 상신하고, 결재자가 승인한다
- Then 견적 잔여수량 4, 주문 잔여수량 0·상태 완료, 매출전표 CONFIRMED, InventoryLedger에 A/W1 -6 1행(sourceType=SALES), 채권 660,000원(공급가 600,000 + 부가세 60,000), JournalEntry 1건(차 외상매출금 660,000 / 대 매출 600,000, 부가세예수금 60,000 + 매출원가/재고 분개), 감사로그·알림 아웃박스 생성 — 모두 같은 트랜잭션 커밋
- When 수금 660,000원을 등록·확정한다
- Then Receivable 잔액 0, SettlementMatch 1행, 수금 분개 1건, 거래처 미수 잔액 0

### E2E-02 구매요청 → 결재 → 발주 → 입고·매입 → 회계분개 → 지급 → 채무소진
- Given 구매요청 양식, 매입처 P, 품목 B(단가 5,000), 구매 담당 U2
- When U2가 구매요청(B×100)을 기안하고 결재가 승인된다
- Then 구매요청 상태 APPROVED, 발주 가능 잔여 100
- When 발주서 60개를 생성하고 다시 40개를 생성한다 (부분 발주)
- Then 잔여 0, 세 번째 발주 시도는 잔여수량 초과로 거부
- When 발주 60개에 대해 매입전표(입고창고 W1)를 확정한다
- Then InventoryLedger B/W1 +60 (unitCost 5,000), Payable 330,000원, 매입 분개(차 재고/상품 300,000, 부가세대급금 30,000 / 대 외상매입금 330,000)
- When 지급 330,000원 확정
- Then Payable 잔액 0, 지급 분개 생성

### E2E-03 휴가신청 → 결재 → 연차사용원장 → 근태반영
- Given 사원 E1(입사 2년차, 연차 부여 15일, 사용 0), 휴가 양식, 결재선(부서장)
- When E1이 2026-09-10~09-11 연차 2일 신청을 상신하고 부서장이 승인한다
- Then LeaveUsage +2(원장), 잔여 13, Attendance 2건 상태 LEAVE, 문서 APPROVED, 알림 아웃박스
- When 승인된 휴가를 취소문서로 취소한다
- Then LeaveUsage -2 반대행 생성(기존 행 유지), 잔여 15, Attendance 원복

### E2E-04 확정 전표 취소 → 재고 반대원장 → 채권채무 원복 → 회계 역분개
- Given E2E-01의 확정 매출전표(수금 전)
- When 취소 사유를 입력해 취소한다
- Then 매출전표 CANCELED, InventoryLedger A/W1 +6 반대행(원행 유지, sourceId 연결), Receivable 0(원복 행), 역분개 JournalEntry(reversalOf 원분개), 감사로그 — 같은 트랜잭션
- Given 수금이 배분된 매출전표
- When 취소를 시도한다
- Then 배분된 수금이 있어 거부되거나(정책) 재배분 안내; 원장 삭제 없음

## B. 경계시험

### B-01 마감기간 차단 (SLS-12, ACC-08, DEC-04)
- Given 2026-07 마감
- When 전표일 2026-07-15 매출전표 생성/확정/취소, 회계전표 생성 시도
- Then 모두 거부(PERIOD_CLOSED); 권한자가 사유 입력 후 해제하면 허용; 해제 사유가 감사로그에 남음

### B-02 권한우회 (INT-12, NFR-SEC-01/02)
- Given 사업부 D1 범위 사용자 U1, D2 매출전표 X, 인사권한 없는 U1
- When U1이 X를 ID로 직접 조회·수정·엑셀 내보내기 하고, 타인 사원의 민감정보를 조회한다
- Then 모두 403(FORBIDDEN); 목록에도 미노출; 감사에 보안이벤트 기록

### B-03 중복요청 (INT-05, INT-11)
- Given 확정 요청 requestId R1
- When R1로 확정을 2회(또는 동시 2회) 호출
- Then 원장·분개·채권 각 1건, 두 번째 응답은 첫 결과 재사용

### B-04 동시출고 (INT-06, INT-08, INV-06)
- Given A/W1 재고 10, 마이너스 재고 차단 설정
- When 8개 출고 전표 2건을 동시에 확정
- Then 정확히 1건만 성공, 다른 1건은 INSUFFICIENT_STOCK; 원장 합계 2; 실제 PostgreSQL에서 20회 반복 동일

### B-05 부분전환 (SLS-02/04/13)
- Given 견적 라인 10
- When 6 전환, 이어서 5 전환 시도, 동시 3·3 전환
- Then 5 전환은 거부(잔여 4), 동시 3·3 중 하나는 거부 또는 순차 처리 후 잔여 ≥ 0

### B-06 부분소진 (SLS-10)
- Given 미수 3건(오래된 순 100, 200, 300)
- When 250 수금 자동배분
- Then 100 전액, 150 부분; 세 번째 0; 수동 재배분 시 이력 보관; 초과 배분(총 700) 시도는 거부

### B-07 확정 후 수정 차단 (INT-03, APV-12)
- Given CONFIRMED 매출전표, APPROVED 결재문서
- When update 호출
- Then 거부(IMMUTABLE); 취소 후 재작성만 허용

### B-08 승인 트랜잭션 원자성 (INT-06)
- Given 승인 핸들러 내 회계 분개 단계에 장애 주입
- When 승인
- Then 결재문서·전표·재고원장·채권·감사로그·아웃박스 모두 롤백, 문서 상태 IN_PROGRESS 유지

### B-09 커밋 후 이메일 실패 (INT-10)
- Given SMTP 실패 주입
- When 확정
- Then 업무 데이터 커밋 유지, OutboxEvent attempt 증가·nextAttemptAt 설정, 5회 후 FAILED 및 실패작업 화면 노출

### B-10 채번 동시성 (BAS-01, APV-13, INT-11)
- When 50개 요청이 동시에 품목 코드 채번
- Then 중복 없음, 결번 없음(또는 결번 허용 정책 명시)

### B-11 월 총평균 평가 (DEC-01, INV-09)
- Given 전월말 확정: 10개 @1,000. 당월: 입고 10 @1,200, 출고 5, 입고 10 @1,500, 출고 8
- Then 잠정: 첫 출고 단가 (10,000+12,000)/20 = 1,100; 마감 확정 평균 = (10,000+12,000+15,000)/30 = 1,233(원단위 절사), 출고 13개 원가 = 16,029, 잠정 합계와 차이는 마감조정 원장·분개로 반영; 기말 17개 = 37,000 − 16,029 = 20,971

### B-12 부가세 계산 (DEC-02)
- Given 라인1 수량 3 × 단가 1,333(과세), 라인2 수량 1.5 × 단가 1,001(면세)
- Then 라인1 공급가 3,999, 부가세 399; 라인2 공급가 1,501, 부가세 0; 합계 공급가 5,500, 부가세 399, 총액 5,899

### B-13 감사로그 민감정보 (INT-09, NFR-SEC-06)
- When 비밀번호 변경, 사원 주민번호 등록, 세션 발급
- Then AuditLog before/after에 원문 없음(마스킹 또는 제거), 애플리케이션 로그에도 없음

### B-14 로그인 잠금·세션 (NFR-SEC-03/04)
- When 5회 연속 실패
- Then 잠금, 관리자 해제 후 로그인 가능; 로그아웃/비밀번호 변경 시 세션 폐기; 로그인 시 세션 ID 회전

### B-15 시점조회 (HRM-02/03)
- Given 2026-06-01 조직개편(D1→D1a, D1b)
- When 2026-05-15 기준 조직도·사원 소속 조회
- Then 개편 전 구조 재현
