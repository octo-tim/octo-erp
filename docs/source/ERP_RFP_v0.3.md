## 1. 사업 개요

### 1.1 목적

현재 상용 ERP(이카운트)에 분산되어 있는 기초정보·매출/매입·재고·회계 업무를 자사 프로세스에 맞춘 웹 기반 경영관리 시스템으로 통합한다. 엑셀 업로드·재입력 등 수작업을 줄이고, 전표 단위의 단일 원장과 실시간 경영지표를 확보한다.

### 1.2 배경

- 다중 사업부(건축자재 유통, 필름 수입, 공동구매, 자체 브랜드) 구조를 표준 ERP에 충분히 반영하기 어렵다.
- 일부 지표는 ERP 자료를 내려받아 별도 시스템에 재입력하고 있다.
- 사업부별 손익·재고·채권채무를 즉시 확인할 통합 화면이 없다.

### 1.3 기대 효과

- 전표·재고·회계 데이터의 단일 원장화 및 중복 입력 제거
- 재고 실시간 파악과 안전재고 미달 사전 인지
- 기간·품목·거래처·사업부별 실적의 즉시 조회
- 전자결재를 통한 전표 확정 통제와 감사 추적성 확보
- 인사·조직 정보를 계정·권한·결재선과 일관되게 연결

## 4. 사용 규모와 목표 구조

| 사업부 | 6개 |
| 임직원 | 10명 |
| 월 결재문서 | 150건 |

### 4.2 목표 구조

```text
[인사·조직] ──▶ [계정·권한·결재선]
      │                    │
      └──────────────▶ [전자결재]
                             │ 승인
[기초정보] ─▶ [매출·매입·발주 전표] ─▶ [재고 원장]
                       │             │
                       └──────▶ [회계 원장]
                                      │
              [통합 보고서·대시보드] ◀┘
```

인사 마스터는 사용자·부서·결재선의 원천이다. 전자결재 대상 전표는 승인 완료 시에만 확정되며, 전표 확정에 따른 재고·채권채무·회계·감사기록은 하나의 데이터베이스 트랜잭션에서 처리한다.

## 10. 검수 기준

1. 모든 필수 요구사항 ID에 구현 위치와 시험 증적이 연결되고 시연을 통과한다.
2. 다음 핵심 E2E 흐름을 포함한 승인된 통합시험이 전건 통과한다.
   - 견적 → 주문 → 매출전표 → 결재 → 확정 → 출고 → 회계분개 → 수금 → 채권소진
   - 구매요청 → 결재 → 발주 → 입고·매입 → 회계분개 → 지급 → 채무소진
   - 휴가신청 → 결재 → 연차사용원장 → 근태반영
   - 전표 취소 → 재고 반대원장 → 채권채무 원복 → 회계 역분개
3. 마감·권한우회·중복요청·동시출고·부분전환·부분소진 경계시험을 통과한다.
4. 데이터 이관 대사에서 승인되지 않은 차이가 0건이다.
5. 성능·보안·복구 시험 기준을 충족한다.
6. 중대·높음 결함 잔여가 0건이고 나머지는 승인된 조치계획을 가진다.
7. 필수 산출물과 사용자 교육 2회 이상이 완료된다.

## 부록 B. 용어

| 용어 | 정의 |
|---|---|
| 업무전표 | 거래·재고·회계 효과의 원인이 되는 업무문서 |
| 확정 | 검증과 필요한 결재를 마치고 원장에 영향을 반영하는 상태 전이 |
| 취소 | 확정 효과를 삭제하지 않고 반대원장·역분개로 무효화하는 처리 |
| 원장 | 삭제하지 않는 증감·분개 기록의 집합 |
| 마감 | 특정 기간의 전표 생성·변경·확정을 제한하는 처리 |
| 부문 | 손익과 데이터 접근범위를 구분하는 사업 단위 |
| 전결 | 규정에 따라 상위 결재 없이 하위자가 최종 승인하는 것 |
| 대결 | 결재권자 부재기간에 지정된 대리자가 대신 승인하는 것 |
