## 제외 (Out of Scope)

- 국세청 전자세금계산서 법정 발행, 부가세 신고, 법정 재무제표 확정 (세금계산서는 사내용 PDF·이메일까지)
- 급여 계산, 4대보험·원천징수·연말정산 계산·신고
- 회계 보고서는 내부 관리용 — 모든 회계 출력물에 "내부 관리용이며 세무신고·외부공시용 확정 재무제표가 아님" 문구 표시

## 변경요청 절차

1. 단계 수행 중 발견한 신규 요구사항은 임의 구현하지 않고 `docs/traceability-state.json`의 `__changeRequests`에 `CR-nn`으로 기록한다 (발견 단계, 내용, 관련 ID, 상태).
2. 추적표 생성(`node tools/traceability.mjs`) 시 CHANGE_REQUEST 절에 노출된다.
3. 발주사 승인 시 `docs/requirements.json`에 ID를 추가하거나 기존 ID 상세를 갱신하고, 결정 레지스터·ADR을 갱신한다.
4. 범위 축소·연기는 해당 ID를 `BLOCKED`로 표시하고 사유·영향·책임자·목표일을 기록한다.
