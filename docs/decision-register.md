# 결정 레지스터 (Decision Register)

RFP v0.3 3장 "착수 시 확정할 정책" DEC-01~09의 기본안·대안·영향·결정 상태를 관리한다.
정책은 적용 시작일과 버전을 보관하며, 과거 전표의 계산 결과를 소급 변경하지 않는다(RFP 3장).

**게이트 처리 결정(2026-08-30)**: 발주사 대표(윤경식)가 "RFP 기본안 채택 후 계속 진행"을 지시했다. 아래 모든 DEC는 상태 `PROVISIONALLY_APPROVED(기본안 임시승인)`이며, 착수회의에서 정식 승인 또는 변경한다. 변경 시 해당 정책 버전을 신규 발행하고 관련 ADR·추적표·시험데이터·매뉴얼을 함께 갱신한다.

## 결정 변경 절차

1. 변경 요청을 `docs/traceability-state.json`의 `__changeRequests`에 기록한다.
2. 새 정책 버전(`PolicyVersion`)을 적용 시작일과 함께 등록한다. 과거 버전은 삭제·수정하지 않는다.
3. 영향 요구사항 ID의 상태를 `NOT_VERIFIED`로 되돌리고 시험을 재실행한다.
4. ADR을 갱신(Superseded)하고 매뉴얼·시험데이터를 함께 갱신한다.
