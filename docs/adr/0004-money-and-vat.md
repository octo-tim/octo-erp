# ADR-0004 금액·부가세 계산 (DEC-02)

- 상태: Provisionally Accepted (2026-08-30)

## 결정
통화 KRW, 금액은 정수. 수량은 소수 3자리까지 허용, 단가는 정수(원). 라인 공급가 = floor(수량×단가). 라인 부가세 = 과세 floor(공급가×0.1), 영세·면세 0. 전표 합계는 라인 합. 부가세 포함가 입력 시 공급가 = floor(포함가/1.1), 부가세 = 포함가 − 공급가. 할인은 단가 조정, 에누리는 별도 문서유형(SLS-11).

## 승인 예시 (B-12)
3×1,333 과세 → 3,999 / 399. 1.5×1,001 면세 → 1,501 / 0. 합계 5,500 / 399 / 5,899.

## 구현
`src/lib/money.ts`(decimal.js, ROUND_DOWN), 서버 재계산으로 클라이언트 값 검증. 정책은 PolicyVersion `money.v1`.
