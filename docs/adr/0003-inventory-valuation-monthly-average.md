# ADR-0003 재고 평가: 월 총평균법 (DEC-01)

- 상태: Provisionally Accepted (2026-08-30)

## 결정
월 총평균법. 당월 출고는 잠정단가 `(전월말 확정금액 + 당월 누적입고금액) / (전월말 수량 + 당월 누적입고수량)`(출고 시점 기준, 원단위 절사)로 평가한다. 월 마감(InventoryValuationPeriod.close) 시 확정 평균가 `(전월말 확정금액 + 당월 총입고금액) / (전월말 수량 + 당월 총입고수량)`로 모든 출고를 재계산하고, 잠정 합계와 차이를 `VALUATION_ADJUST` 원장 행과 마감조정 분개(매출원가 ↔ 재고)로 반영한다.

## 승인 계산 예시 (acceptance-scenarios B-11)
전월말 10개@1,000. 입고 10@1,200, 출고 5, 입고 10@1,500, 출고 8.
잠정: 출고1 단가 1,100 → 5,500. 출고2 단가 (22,000+15,000)/30=1,233 → 9,864. 잠정원가 15,364.
확정: 평균 1,233, 출고 13개 원가 16,029. 조정 +665. 기말 17개 = 37,000-16,029 = 20,971.

## 결과
InventoryLedger는 quantity, unitCost(잠정), amount를 갖고 마감 시 조정행이 추가된다. 이동평균법으로 바꾸지 않는다.
