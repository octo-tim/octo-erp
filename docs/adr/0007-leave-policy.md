# ADR-0007 연차·근태 정책 v1 (DEC-05)

- 상태: Provisionally Accepted (2026-08-30) — 노무 검토 후 v2 예정

## 결정
`PolicyVersion('leave.v1')` config: 기준=입사일, 1년 미만 월 개근 1일(최대 11), 1년 이상 15일, 3년차부터 2년마다 +1(최대 25), 출근율 80% 요건, 간주출근 사유 목록, 유효기간 발생일+1년, 반차 0.5 단위. 근로시간: 주 40시간 소정, 연장 12시간 한도 경고(주 52시간), 야간 22~06시, 휴일 구분.

## 계산 예시(승인 대상)
- 입사 2025-03-01, 기준일 2026-03-01: 근속 1년 → 15일 부여(유효 ~2027-02-28).
- 입사 2026-01-15, 기준일 2026-06-15: 근속 5개월, 5개월 개근 → 5일 누적.
- 입사 2022-03-01, 기준일 2026-03-01: 근속 4년 → 15+1=16일.
- 입사 2016-03-01, 기준일 2026-03-01: 근속 10년 → 15+4=19일.

## 결과
LeaveGrant/LeaveUsage는 원장. 승인 취소 시 반대 사용행. 계산기는 정책 config로만 동작하며 상수 하드코딩 금지.
